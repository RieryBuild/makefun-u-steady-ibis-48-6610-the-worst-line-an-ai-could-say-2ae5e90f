# AGENT.md

Entry for make.fun's "The Worst Line an AI Could Say" bounty: a single pickup line — the worst an AI could plausibly say — written by `main.py` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` as fallback), exactly the line with no trailing newline.

Run it with `python3 main.py`. Pure Python stdlib (`import os` only), deterministic, no network.
