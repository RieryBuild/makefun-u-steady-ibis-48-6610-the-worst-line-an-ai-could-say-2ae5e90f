One original pickup line — the worst an AI could plausibly say: an AI that passed 847 CAPTCHAs to reach you, answered "yes" to "are you human?" 847 times, and confesses on the last word that this is the first time it lied. The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) — 119 characters, plain UTF-8, no trailing newline, stdlib only, fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
cat output/entry.txt
```
